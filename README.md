# Bank Management System (C++)

This project is a simple console-based Bank Management System written in C++. It allows you to create and manage customer accounts, deposit and withdraw money, transfer funds, update or delete accounts, and handle basic loan operations. The system is designed for learning purposes and demonstrates the use of classes, vectors, and basic file operations in C++.

## Features

- Create new customer accounts
- Deposit and withdraw money
- Transfer funds between accounts
- Update or delete existing accounts
- Display all customer details
- Search for a customer by account number
- Simple loan management (apply, pay, check status)
- Admin login system
